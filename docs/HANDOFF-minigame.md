## 3. 发现的问题（要策划部定，引擎没改）

### 3.1 逆风翻盘偏多：27.6–29.6%

2000 局拆分，主称号是“逆风翻盘”的局按触发原因分：

| 触发原因 | 占全部对局 |
|---|---|
| 副业耗尽（`EVT_D_STARTUP` side / exhaust）| 9.7% |
| 正式破产重组 | 8.9% |
| 其他创业关停 | 5.6% |
| **18 岁选“创始人”就失败（`EVT_D_OPEN_CAREER` founder / flop）** | 3.5% |

后两种情况下，“危机前净资产”只是 18 岁的起始资金，翻盘门槛于是退化成 50 万（实际值），很容易达到。结局文案还会写成“18 岁那年几乎跌到谷底”。建议：

- 副业耗尽、18 岁创业失败不算硬危机（只是不设 `had_venture_closed`，或者另设一个标志）；
- 或者 `age_crisis` 取“净资产回撤最大的那次”，而不是第一次。

这和开发部 OPEN-ISSUES #4 是同一件事。

### 3.2 继承自 H5 版的其他待办

`HANDOFF-product.md` §8.5 第 1–4 条照旧：验收用例 3-a/3-c/4-a，高收入困局 / 纸面富翁贴着 1.5% 线（这版 2.0% / 0.7%）。

## 4. 上架前要办的事（公司主体，可和开发并行）

按微信小游戏接入指南的流程：

1. **注册小游戏账号**：用没注册过公众平台的邮箱注册，选“游戏”类目，主体选公司。
2. **微信认证**：企业认证（年审费用以平台为准）。
3. **软著或电子版权认证**：每款游戏都要。申请材料需要源代码片段和操作说明，本仓库可以直接导出。
4. **小程序备案**：免费广告游戏走“情况二”，官方写的是约 10–30 个工作日，最慢，建议最先办。
5. **适龄提示**：在后台设置。
6. **IAA 资质审核**：按后台“资质审核-IAA”页面准备材料。
7. **流量主**：开通后申请激励视频、插屏广告位，把 ID 填进 `js/config.js`。
8. **提审**：上传代码 → 体验版真机测试 → 提交审核。

拿到 AppID 后要改的地方：`project.config.json` 的 `appid`、`js/config.js` 的广告位 ID。

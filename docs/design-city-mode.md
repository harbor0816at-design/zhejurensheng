# 《这局人生》· 当市长模式 设计说明

- 版本：city-1.0.0（MVP）｜2026-11-15
- 决定：作为《这局人生》里的新模式（首页“全球商业 / 当市长”切换）；经典城建核心玩法；2.5D 等距视角；自由建造 + 历史剧本“深圳 1980”两种都要。
- 原创玩法与美术，不使用任何商业城建游戏的名称、标志或素材。

## 玩法

- 32×32 的地图：草地、水面（可以修桥）、树林、沙滩。
- 工具：道路（拖动画 L 形）、住宅 / 商业 / 工业区（拖框）、拆除、电厂、水厂、消防、警察、医院、学校、公园、地铁站（单击放置，要紧挨道路）。
- 一个 tick = 一个月，可以暂停、正常速度、快进。
- **路网**：水电按路网分配，电厂、水厂只给和自己连通的路网供应。分区格要在道路 2 格内才能长楼。
- **需求（住 / 商 / 工）**：住宅需求看岗位和劳动力；商业需求看人口；工业需求看人口和外需。税率越高，需求越低。剧本事件会额外调整需求。
- **生长**：空地在有需求、有富余电力时长出低层楼；地价够、水电齐、公共服务到位就往上长。第 3 层需要学校或医院覆盖，第 4 层（摩天楼）需要学校、医院和地铁同时覆盖。楼层上限随人口里程碑解锁（2,500 / 8,000）。
- **地价**：靠近水和树林加分；公园、警察、消防、医院、学校、地铁覆盖加分；污染扣分（工业、燃煤电厂）。
- **财政**：按人口和岗位收税，道路和设施每月付维护费。可以借款（每笔 2 万元，最多 3 笔）。
- **风险**：没有消防覆盖的建筑更容易着火；断水断电会让楼层下降。
- **里程碑称号**：小村 → 小镇 → 城镇 → 城市 → 大城市 → 都市 → 超级都市。人口达到 300 解锁消防和警察，1,000 解锁医院和学校，10,000 解锁地铁（自由模式）。
- **数据视图**：地价、污染、电力、供水、公共服务覆盖。

## 深圳 1980 剧本

1980–2020 年，按真实年代触发事件（游戏效果为示意）：

| 年份 | 事件 | 游戏效果 |
|---|---|---|
| 1980 | 经济特区设立 | 工业需求大涨 10 年 |
| 1983 | 建设热潮 | 商业需求上升 |
| 1987 | 第一次土地使用权拍卖 | 财政一次性加 2 万 |
| 1990 | 证券交易所开业 | 商业需求上升 |
| 1997 | 亚洲金融危机 | 工业需求下降 |
| 2001 | 加入世贸组织 | 工业需求上升 |
| 2004 | 地铁开通 | 解锁地铁站 |
| 2008 | 全球金融危机 | 工业需求下降 |
| 2010 | 产业升级 | 工业污染减半 |
| 2015 | 创新之城 | 住宅需求上升 |
| 2020 | 疫情冲击 | 剧本结束 |

5 个人口目标（1985：600；1992：2,000；2000：5,000；2010：10,000；2020：18,000），每达成一个得一颗星。剧本结束后可以继续自由建设。

## 代码

- `js/city/sim.js`：模拟引擎（确定性，同一种子同样操作结果一样）
- `js/city/render.js`：等距渲染
- `js/screens/city.js`：地图页、预算页、事件页、剧本结局页
- `tools/city-auto.cjs`：自动建城测试；`tools/play-city.cjs`：浏览器走查

## 待做 / 待验证

- 平衡只用简单的自动策略粗调过，需要真人试玩后再调：目标人口、税收、维护费、需求曲线。
- 真机性能：每 90 毫秒重绘约 1000 个地块，需要在中低端安卓机上实测，必要时改成离屏缓存地形层。
- 第二阶段：逐车交通和拥堵、公交线路、更多地图尺寸、更多历史剧本（如浦东 1990）、和商业版打通（公司开在自己建的城市里）。

# 《这局人生》· 当市长模式 设计说明

- 版本：city-2.0.0｜2026-11-15
- 决定：作为《这局人生》里的新模式（首页“全球商业 / 当市长”切换）；经典城建核心玩法；**俯视（正上方）视角**（2.5D 等距已按用户要求放弃）；6 个历史剧本 + 自由建造（6 种地图 × 3 档资金 × 7 张可叠加的挑战卡）。
- 原创玩法与美术，不使用任何商业城建游戏的名称、标志或素材。
## 玩法

- 32×32 的地图：草地、水面（可以修桥）、树林、沙滩。
- 工具：道路（拖动画 L 形）、住宅 / 商业 / 工业区（拖框）、拆除、电厂、水厂、消防、警察、医院、学校、公园、地铁站（单击放置，要紧挨道路）。
- 一个 tick = 一个月，可以暂停、正常速度、快进。
- **路网**：水电按路网分配，电厂、水厂只给和自己连通的路网供应。分区格要在道路 2 格内才能长楼。
- **需求（住 / 商 / 工）**：住宅需求看岗位和劳动力；商业需求看人口；工业需求看人口和外需。税率越高，需求越低。剧本事件会额外调整需求。
- **生长**：空地在有需求、有富余电力时长出低层楼；地价够、水电齐、公共服务到位就往上长。第 3 层需要学校或医院覆盖，第 4 层（摩天楼）需要学校、医院和地铁同时覆盖。楼层上限随人口里程碑解锁（2,500 / 8,000）。
- **地价**：靠近水和树林加分；公园、警察、消防、医院、学校、地铁覆盖加分；污染扣分（工业、燃煤电厂）。
- **财政**：按人口和岗位收税，道路和设施每月付维护费。可以借款（每笔 2 万元，最多 3 笔）。
- **风险**：没有消防覆盖的建筑更容易着火；断水断电会让楼层下降。
- **里程碑称号**：小村 → 小镇 → 城镇 → 城市 → 大城市 → 都市 → 超级都市。人口达到 300 解锁消防和警察，1,000 解锁医院和学校，10,000 解锁地铁（自由模式）。
- **数据视图**：地价、污染、电力、供水、公共服务覆盖。

## 历史剧本（js/city/scenarios.js）

每个剧本有自己的地图、起步资金、规则修正、按真实年代触发的事件和 5 个限时目标（每达成一个得一颗星），结束后可以继续自由建设。事件效果为游戏示意。

| 剧本 | 年代 | 地图特点 | 玩法重点 |
|---|---|---|---|
| 深圳 | 1980–2020 | 渔村 + 海湾 | 特区设立、入世、产业升级；人口和摩天楼目标 |
| 浦东 | 1990–2020 | 江对岸老城区已建好 | 跨江修桥、陆家嘴金融区、商业占比 |
| 新加坡 | 1965–2015 | 小岛、土地极少 | 填海、组屋、公园城市、少地高密度 |
| 迪拜 | 1971–2020 | 沙漠 + 海岸，水很贵 | 石油收入先行、后期转型商业和旅游 |
| 底特律 | 1950–2020 | 已建成的汽车城，钱少 | 工业衰退、人口流失、维护费高；目标是“守住”和转型 |
| 重庆 | 1997–2020 | 山地，岩石只能修隧道道路 | 直辖市、地形成本、地铁 |

目标类型：人口、摩天楼数、建成面积、公园数、商业占比、资金、地铁站数、人口保持率。

## 自由建造

- 地图：河流、海岸、群岛、沙漠、山地、湖区（`js/city/maps.js`，按种子生成）。
- 起步资金：宽裕 7 万 / 普通 4 万 / 紧张 1.8 万。
- 挑战卡（可多选叠加）：火灾频发、雾霾、电力紧张、移民潮、财政紧缩、绿色城市、天灾。

## 代码

- `js/city/sim.js`：模拟引擎（确定性，同一种子同样操作结果一样）
- `js/city/maps.js` / `js/city/scenarios.js`：地图生成、剧本与挑战卡数据
- `js/city/render.js`：俯视渲染（地面 → 阴影 → 建筑屋顶 → 叠加层四遍绘制）
- `js/screens/city.js`：地图页、预算页、事件页、剧本结局页
- `tools/city-auto.cjs`：自动建城测试；`tools/play-city.cjs`：浏览器走查

## 待做 / 待验证

- 平衡只用简单的自动策略粗调过，需要真人试玩后再调：目标人口、税收、维护费、需求曲线。
- 真机性能：每 90 毫秒重绘约 1000 个地块，需要在中低端安卓机上实测，必要时改成离屏缓存地形层。
- 第二阶段：逐车交通和拥堵、公交线路、更多地图尺寸、和商业版打通（公司开在自己建的城市里）。

# 《这局人生》V2：全球商业决策版 · 设计说明

- 版本：2.0-draft｜2026-11-15
- 决定（来自负责人 2026-11-15）：
  1. 玩法 = 主线经营一家公司 + 途中遇到改编自经典商业案例的关键抉择；
  2. 案例自写，可用真实公司名；不使用任何商学院案例原文或期刊品牌；
  3. 真实国家与真实经济史，**不画世界地图**（规避国内上架的审图要求），用国家卡片呈现；
  4. 主要互动 = 全球市场棋盘（拖拽布局）。
- V1（18–65 岁个人人生模拟）整体移到 `legacy/`，不再打包。

## 1. 一局怎么玩

- 玩家创办一家公司：选行业（消费电子 / 饮料快消 / 软件互联网 / 汽车制造 / 服装零售）、总部国家（9 国任选）、开局年份（1995 / 2005 / 2015）、创始背景（白手起家 / 家族企业 / 风投初创 / 国企分拆 / 技术极客），给公司起名；也可以一键随机组合。
- 1995 年开局，**每年一回合**，2024 年结束，共 30 回合，10–15 分钟。
- 每年三件事：
  1. **看新闻**：顶部滚动当年真实的宏观大事，如 1997 亚洲金融危机、2001 中国入世、2008 金融危机、2020 疫情；
  2. **摆棋盘**：把行动块拖到国家格子上（出口进入、设分公司、建工厂、营销战役、撤出），每年有 3–5 个行动点；
  3. **定总部战略**：研发投入、定价（低价 / 平价 / 溢价）、借款 / 还款。
- 点“结束这一年”看年报：利润瀑布图、各国收入、估值变化。
- 大约每 2–3 年遇到一次**案例时刻**：站在某家真实公司当年的位置做抉择，例如 1999 年柯达面对数码相机、2007 年诺基亚面对 iPhone、2003 年 eBay 在中国遇到淘宝。选完后揭晓：你的结果、当年真实的走向，以及背后的理论（颠覆式创新、蓝海、CAGE 距离、网络效应……）。
- 结局：企业估值 + 称号（全球巨头 / 区域霸主 / 隐形冠军 / 浴火重生……）+ 案例复盘（你的选择和历史对照）。
- 坚持 V1 的原则：现金不够时自动用信用额度，额度用完进入**重组**（卖掉部分海外业务、股权稀释），**不结束游戏**；经济结算全部是确定性代码，同一个种子同样的操作结果完全一样。

## 3. 经济模型（`js/biz/engine.js`）

- **份额**：吸引力 = 布局等级 × 当地品牌 × 产品力 × 价格 × 准入 × 本地化；目标份额 = 吸引力 ÷（吸引力 + 竞争强度）；每年向目标份额靠拢 45%。软件行业有网络效应（份额越高，吸引力越大）。
- **收入** = 市场规模 × 份额 × 定价系数。
- **成本**：实物行业选成本最低的供货地（自有工厂或代工），叠加人工成本指数、关税、物流；软件主要是研发和服务器成本。
- **固定费用**：每个国家按布局等级收，乘当地成本指数；另有研发和总部管理费。
- **现金恒等式**：期末现金 = 期初现金 + 净利润 − 资本开支 + 净融资，逐年校验（误差 ≤ 0.01 美元）。
- **估值** = 净利润 × 行业市盈率 × 市场情绪（1999–2000 软件泡沫、2001–02 泡沫破裂、2008–09 危机、2020–21 线上化、2023 AI 热）+ 现金 − 负债。
- **随机**：种子派生 4 条独立随机流（宏观、市场、案例、事件），互不干扰。

## 4. 案例卡

每张卡包括：情景（用自己的话写的真实背景 + 你的处境）、2–3 个选项（带概率结果）、揭晓（你的结果 / 真实历史 / 理论视角）。全部内容原创撰写，不引用任何案例原文。

- **通用**：亚洲金融危机抄底、中国入世进入方式、2008 危机里的裁员与投资、贸易摩擦下的供应链“+1”、疫情现金与线上化、通胀下的定价权
- **消费电子**：柯达式自我颠覆、诺基亚面对智能手机、任天堂 Wii 式蓝海、Note7 式召回危机
- **饮料快消**：全球标准化还是本地化（可口可乐在印度保留 Thums Up）、合资伙伴另起炉灶（达能与娃哈哈）、开创新品类（红牛）、改不改经典配方（1985 年新可乐）
- **软件互联网**：泡沫顶点融资（亚马逊 2000 年发可转债）、免费的本土对手（eBay 与淘宝）、把内部设施卖给外部（AWS）、拆分老业务（Netflix 的 Qwikster）

## 多样性更新（引擎 2.1.0，2026-11-15）

- **行业**：新增汽车制造（工厂投入 ×2、毛利薄、后期电动化）和服装零售（亚洲代工、潮流快、近岸快反）。
- **开局年份**：2005 / 2015 开局时，起步资金按经济规模放大（每晚一年 +6%），之前年份的案例自动跳过。
- **创始背景**（`D.FOUNDERS`）：起步现金、产品力、本土品牌、持股比例、初始债务、信用额度、行动点都不同。
- **案例**：通用案例新增互联网热潮、服务外包、欧债危机抄底、英国脱欧、碳中和、生成式 AI；汽车 5 张（精益生产、电动化、排放门、大规模召回、缺芯），服装 4 张（快时尚、零售国际化、供应链责任、全渠道）。共 30 张，文件 `js/biz/cases.js`、`js/biz/cases2.js`。
- **随机经营事件**（`js/biz/events.js`）：没有历史案例的年份有一半概率抛出一张，如挖角、网红爆款、专利官司、工厂失火、数据泄露、罢工、大客户压价、招商引资、山寨货、价格战、汇率跳水等，每局每张最多一次，约 3 张/局。
- **结局**：新增超级独角兽、百年老店、老树新花、技术信仰、后发先至、世界工厂主、屡败屡战、盛极而衰、丑闻缠身，共 20 种。
- 蒙特卡洛（900 局 × 4 种策略，覆盖全部组合）：现金恒等式误差 0；软件行业仍明显最强、汽车最弱，需真人试玩后再平衡。


## 3.0 更新：打到 2074、允许破产、经营细节（引擎 3.0.0，2026-11-16）

用户反馈六点：案例不够丰富、背景不够丰富、操作不够细节、解决方式不够多样、估值曲线要允许破产、视野要放到未来 50 年。对应改动：

**时间线**
- 所有局都打到 2074 年；开局年份 1995 / 2005 / 2015 / 2025。
- 2025–2074 由 `js/biz/future.js` 按种子推演：技术（AI 大爆发 / 稳步渗透 / 泡沫破裂）× 地缘（再全球化 / 阵营分裂 / 多极摇摆）× 气候（有序转型 / 急刹车 / 转型失败）共 27 种组合，再叠加随机金融危机、疫情、灾害。GDP、人工成本、行业渗透率、关税、准入、利率都随推演变化。界面上标“推演”。
- 结局金额门槛按名义经济规模放大。

**破产**
- 现金断了先用信用额度，再重组；每种出身有重组上限（风投、家族 1 次，国企、员工持股 3 次，其他 2 次），用完就破产清算，游戏结束，估值曲线归零并打叉。

**背景**
- 行业 7 个：新增医药健康、新能源。
- 创始背景 10 种：新增海归精英、草根销售、跨国公司分拆、连续创业者、员工持股。
- 创始人特长 7 种（营销天才、工程师、财务老手、外交家、供应链专家、冒险家、无）。

**经营细节**（`js/biz/policy.js`，“经营决策”页 5 个分页）
- 产品：产品档次（平价 / 主流 / 高端，可多选，各国按收入水平选最合适的一档）、定价、研发投入、研发方向（降本 / 品质 / 颠覆创新）。
- 资本：贷款、发债（7 年到期）、增发、回购、上市、分红政策、汇率对冲；收购当地对手（国家页，花 1 个行动点）。
- 组织：人员规模、薪酬、CEO 人选、组织架构（改动有费用和 2 年冷却）、企业文化（3 年冷却）。
- 供应链：供应商、库存、销售渠道（线下 / 电商 / 社交 / 全渠道 / 2030 年后的 AI 代理）、本地化程度。

**案例与解法**
- 案例 91 个：历史 52 个（新增非典、东日本大地震、移动互联网、印度废钞、油价暴跌、中国人工成本上升、乳业危机、平台反垄断、芯片断供，医药 4 个、新能源 4 个），未来推演 39 个（通用 25 个 + 每个行业 2 个），按大势拨盘出现。
- 老案例都补了第四种解法（`js/biz/options_extra.js`）。
- 每张案例都可以先“请咨询公司”（看清各结果概率）、“找伙伴分担”（代价和收获打五五折）或“推迟一年”。
- 随机经营事件 20 张，可在 15 年后重复出现。

**蒙特卡洛（300 局 × 4 种策略）**：现金恒等式误差 < 0.01 美元；破产率稳健 3%、随机 14%、激进 26%、被动 7%；结局分布分散。软件仍明显最强，汽车和新能源对激进扩张最不友好。需要真人试玩继续调平衡。
